## 🎯 Objetivo do Projeto

O principal objetivo deste projeto é criar uma página HTML estruturada de forma clara e semântica. A atividade foca na aplicação correta das tags fundamentais estudadas em aula, organizando elementos como textos, títulos, mídias e hiperlinks.

## 📌 Descrição da Página

A página apresenta uma ficha técnica detalhada e informações sobre o filme de terror psicológico **Nós (Us)**. 

### 🗂️ Conteúdo Apresentado
* **Informações Técnicas:** Ano de produção, diretor, duração, classificação indicativa, gênero e país de origem.
* **Mídia:** Inclusão de uma imagem ilustrativa relacionada à obra.
* **Conteúdo Textual:** Uma breve sinopse do enredo do filme.
* **Navegação:** Um link externo direcionando o usuário para páginas com mais detalhes sobre a produção.

### 🏷️ Tags HTML Praticadas
O projeto demonstra a aplicação prática da estrutura básica e de tags essenciais, tais como:
* `<title>` (Definição do título na aba do navegador)
* `<h1>` e `<h2>` (Hierarquia de títulos)
* `<p>` (Parágrafos de texto)
* `<img>` (Inserção de imagens com atributos de acessibilidade)
* `<a>` (Links de navegação)
